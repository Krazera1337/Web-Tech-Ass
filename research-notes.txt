NAME VERIFICATION METHOD
- Checked each of the 16 species against POWO (powo.science.kew.org, via WebSearch + direct API calls)
  and cross-confirmed against GBIF Backbone Taxonomy (api.gbif.org/v1/species/match), which mirrors
  the WCVP/POWO accepted-name backbone. IUCN status pulled from GBIF's aggregated IUCN Red List
  distribution data (api.gbif.org .../distributions), which cites "The IUCN Red List of Threatened
  Species" as source. Wikipedia used only for cross-checking spelling / common names, never as primary
  taxonomic authority.

NAME CORRECTIONS MADE
1. "Parastemon glaucum" (as given in the task) does NOT exist in POWO, GBIF, or IUCN. The genus
   Parastemon (Chrysobalanaceae) has only a small number of accepted species, and none is named
   "glaucum". The clearly intended species is Parastemon grandifructus Prance - an accepted name,
   endemic to Borneo (Sarawak, Sabah) and Brunei, IUCN status Vulnerable. Used P. grandifructus in
   place of "P. glaucum" for all data.

TECHNICAL NOTE ON RATE LIMITING: After downloading roughly 10 full-resolution original images in quick
succession, Wikimedia's upload.wikimedia.org returned HTTP 429 with "Retry-After: 600" and the
message: "please... use thumbnail images in sizes listed on https://w.wiki/GHai" (this redirects to
mediawiki.org/wiki/Common_thumbnail_sizes). The allowed thumbnail widths are exactly: 20, 40, 60, 120,
250, 330, 500, 960, 1280, 1920, 3840px - NOT arbitrary widths like 800px (which is why earlier 800px
thumbnail requests returned HTTP 400). Remaining downloads were re-queued as a background job using the
proper /thumb/.../960px-filename URL format and a 10-minute cooldown wait, per Wikimedia's own
instructions in the 429 response, and all completed successfully afterwards (two files needed one
additional short retry). All downloaded images (whether via curl originals + local resize, or via the
960px Commons thumbnail endpoint) were then normalised to a max width of 800px, JPEG quality ~82, using
a PowerShell/.NET System.Drawing script, keeping every file in images/ under ~550 KB (most under
300 KB) - reasonable for a student web page.
